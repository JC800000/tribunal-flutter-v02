PROGRAMAS REQUERIDOS (descargar e instalar en este orden):
----------------------------------------------------------

1. PYTHON 3.13
   Descargar: https://www.python.org/downloads/
   IMPORTANTE: Durante la instalacion marcar la casilla
               "Add Python to PATH" antes de instalar

2. NODE.JS 18 o superior
   Descargar: https://nodejs.org/en/download
   Instalar la version LTS (la recomendada)

3. POSTGRESQL 15 o superior
   Descargar: https://www.postgresql.org/download/windows/
   Durante la instalacion configurar:
     - Usuario:    postgres
     - Contrasena: root
     - Puerto:     5432
   Tambien instala pgAdmin automaticamente (para administrar la BD)

4. GIT
   Descargar: https://git-scm.com/download/win
   Instalar con opciones por defecto

5. FLUTTER 3.x (SDK)
   Descargar: https://docs.flutter.dev/get-started/install/windows
   Pasos:
     a) Descomprimir en C:\flutter
     b) Agregar C:\flutter\bin al PATH del sistema:
        - Buscar "variables de entorno" en inicio
        - Variables del sistema > Path > Editar > Nuevo
        - Escribir: C:\flutter\bin
        - Aceptar todo
     c) Abrir terminal y verificar: flutter doctor

6. ANDROID STUDIO
   Descargar: https://developer.android.com/studio
   Durante la instalacion instalar tambien:
     - Android SDK
     - Android SDK Platform-Tools
   Despues abrir Android Studio:
     - SDK Manager > SDK Tools > marcar "Android SDK Command-line Tools"


================================================================
   CONFIGURACION DE LA BASE DE DATOS
================================================================

1. Abrir pgAdmin (se instala con PostgreSQL)
2. Conectarse al servidor local con contrasena: root
3. Click derecho en "Databases" > Create > Database
4. Nombre de la base de datos: expociencia
5. Guardar


================================================================
   CONFIGURACION DEL BACKEND (Django)
================================================================

Abrir una terminal (cmd o PowerShell) en la carpeta del proyecto:

  cd backend

  :: Crear entorno virtual
  python -m venv venv

  :: Activar entorno virtual
  venv\Scripts\activate

  :: Instalar dependencias
  pip install -r requirements.txt

  :: Crear tablas en la base de datos
  python manage.py migrate

  :: Iniciar el servidor backend
  python manage.py runserver 0.0.0.0:8000

Si todo va bien veras:
  Starting development server at http://0.0.0.0:8000/

DEJAR ESTA TERMINAL ABIERTA MIENTRAS SE USA EL SISTEMA.


================================================================
   CONFIGURACION DEL FRONTEND (React)
================================================================

Abrir OTRA terminal en la carpeta del proyecto:

  cd frontend

  :: Instalar dependencias
  npm install

  :: Iniciar el servidor frontend
  npm run dev

Si todo va bien veras:
  Local: http://localhost:5173

Abrir el navegador en: http://localhost:5173

DEJAR ESTA TERMINAL ABIERTA MIENTRAS SE USA EL SISTEMA.


================================================================
   CONFIGURACION DE LA APP MOVIL (Flutter)
================================================================

PASO 1 - Conocer la IP de tu computadora:
  Abrir terminal y escribir: ipconfig
  Buscar "Direccion IPv4" ejemplo: 192.168.1.100

PASO 2 - Actualizar la IP en el codigo:
  Abrir el archivo:
    flutter_tribunal\lib\config\graphql_config.dart
  Cambiar esta linea:
    const String kBackendUrl = 'http://192.168.100.50:8000/graphql/';
  Por la IP de tu computadora:
    const String kBackendUrl = 'http://TU_IP_AQUI:8000/graphql/';

PASO 3 - Compilar la app:
  Abrir terminal en la carpeta del proyecto:

  cd flutter_tribunal

  :: Descargar dependencias Flutter
  flutter pub get

  :: Compilar APK para Android
  flutter build apk --release

  El APK quedara en:
  flutter_tribunal\build\app\outputs\flutter-apk\app-release.apk

PASO 4 - Instalar APK en el celular:
  a) Copiar el archivo app-release.apk al celular
     (por USB, WhatsApp o Google Drive)
  b) En el celular ir a Ajustes > Seguridad >
     Activar "Instalar apps de fuentes desconocidas"
  c) Abrir el APK desde el celular para instalarlo


================================================================
   ABRIR EL PUERTO 8000 EN EL FIREWALL DE WINDOWS
================================================================

Sin este paso el celular no puede conectarse al backend.

1. Buscar "Windows Defender Firewall con seguridad avanzada"
2. Click en "Reglas de entrada" > "Nueva regla"
3. Tipo: Puerto > Siguiente
4. TCP > Puerto especifico: 8000 > Siguiente
5. Permitir la conexion > Siguiente > Siguiente
6. Nombre: Django 8000 > Finalizar


================================================================
   INICIO RAPIDO (cada vez que uses el sistema)
================================================================

Opcion A - Doble click en: iniciar_sistema.bat
           (abre backend y frontend automaticamente)

Opcion B - Manual:
  Terminal 1:  cd backend  > venv\Scripts\activate > python manage.py runserver 0.0.0.0:8000
  Terminal 2:  cd frontend > npm run dev

Luego abrir el navegador en: http://localhost:5173
Y abrir la app en el celular (misma red Wi-Fi que la PC)
